How the workflow maps to the role

Production path

  1. Replace synthetic data with governed transaction, item, promotion, store, and weather tables.
  2. Move feature SQL into dbt or a shared analytics codebase.
  3. Schedule model scoring in Databricks or Airflow.
  4. Publish recommendation adoption, drift, error, and margin impact in Tableau or Power BI.

Applicant note

I built this to show the full analytical operating loop rather than a standalone notebook: define the decision, create a reliable feature layer, estimate model behavior, validate it, translate outputs into actions, and monitor whether the output stays trustworthy.
